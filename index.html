ชนลูกหนี้รายตัวสิทธิเบิกได้ อปท. (LGO) ผู้ป่วยใน กับ Invoice e-Claim IPLGO

จับคู่ด้วย AN · ถ้าไม่พบ AN ใช้ HN + วันจำหน่าย · ประมวลผลในเบราว์เซอร์ ไม่ส่งข้อมูลออกนอกเครื่อง

คู่มือดึงข้อมูลลูกหนี้ IPD อปท. จาก HOSxP XE (SQL)

ขั้นตอน

  1. กดปุ่ม คัดลอก SQL ด้านล่าง
  2. แก้ช่วงวันจำหน่ายในบรรทัด WHERE a.dchdate BETWEEN '2025-10-01' AND '2026-09-30' (รูปแบบ YYYY-MM-DD ปี ค.ศ.) ค่าตั้งต้นคือปีงบ 2569
  3. รันใน HOSxP XE (เมนู SQL Query) หรือ pgAdmin / DBeaver ที่ต่อฐาน PostgreSQL ของ HOSxP
  4. Export ผลลัพธ์เป็น Excel (.xls/.xlsx) หรือ CSV อย่าเปลี่ยนชื่อคอลัมน์
  5. ลากไฟล์ลูกหนี้มาวางพร้อมไฟล์ Invoice IPLGO (eclaim_xxxxx_IPLGO_*.xls หลายไฟล์ หรือ .zip)

หลักการของ SQL

  • ดึง admission ที่จำหน่ายแล้วจาก an_stat ในช่วงวันจำหน่ายที่กำหนด
  • เลือกเฉพาะสิทธิหลักของ admission ที่ pttype.hipdata_code = 'LGO' (เบิกได้ อปท.)
  • เอาเฉพาะรายที่มียอดเรียกเก็บ (uc_money > 0)
ข้อควรรู้: ถ้าโรงพยาบาลตั้งรหัสสิทธิ อปท. ไว้หลายตัว (เช่น 23 จ่ายตรง และรหัสอื่น) แต่บางตัวไม่ได้ผูก hipdata_code = 'LGO' ให้เปลี่ยนเงื่อนไขเป็น a.pttype IN ('23', ...) แทน · มีไฟล์ลูกหนี้จาก SQL ของตัวเองอยู่แล้วก็ใช้ได้ ขอให้มีคอลัมน์ an และ debt_amount
SELECT
    a.dchdate AS dchdate,
    a.hn AS hn,
    a.an AS an,
    p.cid AS cid,
    COALESCE(p.pname,'') || p.fname || ' ' || p.lname AS ptname,
    a.pttype || ' : ' || pt.name AS pttype_name,
    COALESCE(a.uc_money,0) AS debt_amount
FROM an_stat a
JOIN patient p ON p.hn = a.hn
JOIN pttype pt ON pt.pttype = a.pttype
WHERE a.dchdate BETWEEN '2025-10-01' AND '2026-09-30'
  AND pt.hipdata_code = 'LGO'
  AND COALESCE(a.uc_money,0) > 0
ORDER BY a.dchdate, a.an;

รูปแบบไฟล์และวิธีอ่านผล
  • ไฟล์ลูกหนี้ ต้องมีคอลัมน์ an และ debt_amount (มี hn, dchdate, cid, ptname ด้วยยิ่งดี) ชื่อคอลัมน์ภาษาไทย เช่น “วันจำหน่าย”, “ยอดลูกหนี้” ก็อ่านได้
  • ไฟล์ Invoice คือ “รายงานการรักษาผู้ป่วยของหน่วยบริการ สำหรับ Invoice” (eclaim_รหัสรพ_IPLGO_วันที่.xls) ระบบอ่านแผ่น Detail ส่วนแผ่น Summary / Data Drug / Data Instrument ไม่ได้ใช้
  • เบิกได้ = ยอดที่ รพ. ส่งเบิกใน e-Claim (เรียกเก็บ − เบิกไม่ได้) ควรเท่ากับยอดลูกหนี้ ถ้าไม่เท่าจะติดป้าย “ยอดส่งเบิก ≠ ลูกหนี้”
  • ชดเชยสุทธิ = ค่ารักษา + PP ที่ อปท. จ่ายจริง (คิดตาม DRG/AdjRW + ค่าห้อง ค่าอุปกรณ์) จึงมักไม่เท่ายอดลูกหนี้ ส่วนต่างนี้คือยอดที่ต้องปรับปรุงลูกหนี้ (สูงกว่า = รายได้เพิ่ม, ต่ำกว่า = ตัดส่วนต่างลูกหนี้)
  • รายที่มี Error Code หรือชดเชยสุทธิเป็น 0 จะอยู่แท็บ “ติด Error / ไม่ได้ชดเชย” · AN ที่พบในหลาย Invoice จะรวมยอดและติดป้าย “หลายงวด” ให้ตรวจว่าเป็นการแก้ไขส่งใหม่หรือข้อมูลซ้ำ · ใส่ไฟล์เดียวกันซ้ำ ระบบตัดแถวซ้ำด้วย TRAN_ID ให้
ใส่ไฟล์ลูกหนี้และไฟล์ Invoice IPLGO แล้วระบบจะแสดงยอดส่งเบิก ยอดชดเชย ส่วนต่าง และรายที่ยังไม่พบใน Invoice
